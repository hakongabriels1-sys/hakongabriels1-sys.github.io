Om appen

LoL AutoEdit er et privat verktøy som kjører på eierens egen PC. Det redigerer videoopptak og laster dem opp til eierens egen YouTube-kanal. Appen tilbys ikke til andre brukere.

Hvilke data appen bruker

  • Google-konto / YouTube: Når eieren logger inn, får appen en tilgangsnøkkel (OAuth-token) fra Google. Den brukes bare til å laste opp videoer, endre titler på videoer appen har lastet opp og lese navnet på kanalen.
  • Videofiler: Opptak og ferdige videoer leses og lagres bare lokalt på eierens PC, og lastes opp til YouTube når eieren har valgt det.
  • Kampinformasjon: Lagnavn hentes fra GGarena for å gi videoene navn.

Lagring og deling

Tilgangsnøkkelen lagres bare lokalt på eierens PC. Appen har ingen server og samler ikke inn, selger eller deler data med noen andre enn Google/YouTube, som tar imot videoene som lastes opp.

Google API-tjenester

Bruken av informasjon mottatt fra Google API-er følger Google API Services User Data Policy, inkludert kravene om begrenset bruk (Limited Use). Appen bruker YouTube API Services, og ved å bruke appen gjelder også YouTubes vilkår og Googles personvernerklæring.

Tilbakekalle tilgang

Tilgangen kan når som helst trekkes tilbake på myaccount.google.com/permissions, eller ved å trykke «Koble fra» i appen. Da slettes den lokale nøkkelen.
